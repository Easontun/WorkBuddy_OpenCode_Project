# WorkBuddy_OpenCode_Project
💻 WorkBuddy 功能矩阵
纯文本
✅ AI 对话        - 本地智能模式 + 可接入 GPT/Claude API
✅ 代码编辑器     - Python/JS/Java/C++/Go/Rust 语法高亮
✅ 代码运行       - 内置终端直接执行代码
✅ 快捷命令       - 一键 git status / pip install 等
✅ 项目管理       - 打开文件夹自动分析文件树
✅ 项目笔记       - 自动保存的项目级笔记
✅ 对话历史       - 多轮对话，随时回溯
✅ 代码片段库     - 保存/管理常用代码
✅ 深色/浅色主题  - 一键切换
✅ 系统托盘       - 最小化到托盘后台运行
🚀 在 Windows 上使用
解压 zip 包
双击 dist/WorkBuddy_OpenCode.exe 启动
在 设置​ 中填入 API URL + Key 可启用在线 AI 模式
不配置 API 也能用 本地智能模式
